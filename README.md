# One-Line Office Joke: The Printer Reads the Calendar

Entry for the make.fun bounty
[u-markk-st-one-line-office-jokes-a51f2bcc](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc)

`main.py` (Python 3.13, standard library only) writes one original
one-line joke about office life to `/output/entry.txt`: the printer
that only jams on urgent documents, so it must read the calendar
better than the manager does.

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt`.
